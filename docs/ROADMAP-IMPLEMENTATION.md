# Virtual Piano Studio：五條路線實作與驗收

日期：2026-10-25。規劃／監督／驗收：主代理；實作：GPT-6 Luna，High。

## 不變原則

保留 PianoEngine、PlaybackScheduler、現有桌機黑金視覺與所有已修改功能。版面與播放模式獨立，切換不重設播放；重用 Pointer Events 與外部進度訂閱。不新增依賴、不增加後端、不修改發布副本。保留使用者既有未提交變更。使用者於 2026-10-28 已授權全部完成後推上 GitHub 與既有 GPT Sites；完成驗收後依此執行。

## A 好上手的鋼琴

- 中央 16 個半音預設映射可用，無須 Shift；自訂映射與設定保存。
- 綁定有明確等待狀態、Esc 取消與按鍵衝突確認；一般觸控彈琴不因未映射而被設定視窗打斷。
- 初始入口區分直接彈奏與載入曲目練習，沿用鋼琴的探索式琴蓋。
- 曲目與工具、播放設定、全螢幕、專注練習語意清楚。
- 播放中關蓋能控制播放；錄製狀態持續可見。

## B MIDI 陪練

- 支援等音與節奏練習；按對音符才前進。
- 手動指定音軌／音域分工，不把分軌或音域當作自動辨認左右手。
- Piano Roll 拖選一段建立 A/B 循環；速度以 0.05 調整。
- 每首歌獨立保存速度、轉調、循環、音軌分工並還原，不跨曲污染。
- 提供少量可行動的練習回饋，標出適合重練的段落。

## C 一鍵和弦

- 至少 C/G/D/A/F/B♭ 調性配置；按鍵標示與說明一致。
- 柱式、分解、節奏伴奏可選，柔和／剛強／輕快有實際力度與節奏差別。
- 提供可演奏的 I–V–vi–IV 進行，隨調性移調。
- 鬆鍵、失焦、取消模式、換設定或卸載，都清除排程與發聲，無卡音。

## D 個人練習工作室

- 錄製有時長，結束可立即回放，開始新錄製前保留未儲存作品。
- 本機多段作品可命名、改名、刪除與重新開站還原，處理容量與損毀資料錯誤。
- 每段可匯出 MIDI，保持踏板與音符資訊。
- 原曲／演奏可切換比較，不把原曲覆蓋掉。
- 依 MediaRecorder 能力提供實際聲音下載；不支持時保留 MIDI 路徑，不偽裝音訊成功。

## E 觸控與後續擴充

- 琴鍵大小、瀏覽／演奏、曲譜／播放／工具獨立顯示可保存。
- 手機 320/375/390/430，橫向667×375/844×390/932×430。
- 平板768×1024/820×1180/1024×768/1180×820/1366×1024，以及桌機1440×900，無頁面水平溢出、可達控制項。
- 多指與滑奏音符所有權、pointercancel/lostcapture、背景切換清理有回歸測試。
- 原生 Web MIDI：按需連線、力度、踏板、斷線清音、權限或不支持提示。
- 可調鍵標籤、文字對比、音符辨識；手彈與自動有形狀／文字區別，不只靠色彩。
- 分享歌曲來源與練習配置的 URL；驗證輸入，不外傳本地上傳的曲檔。

## 驗收證據

1. 模組測試檢查生命週期／持久化／資料驗證／排程清理；執行 `npx vitest run --exclude "site-publish/**" --exclude ".sites-stage/**"`。
2. `npm run build`，確認靜態部署相對路徑與無新增依賴。
3. 瀏覽器實際走過初始入口、面板、播放、綁定、陪練、和弦、錄製／回放／分享；檢查上述尺寸並保存截圖。
4. 真機觸控／輸出延遲／實體MIDI裝置不能用視窗模擬或測試替代。實際未測項目留在 TESTING.md，沒有證據不能標為通過。
5. 全部五路線逐項對照後才標記整體完成；進度以實際程式與驗收結果為準。
