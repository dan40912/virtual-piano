## 已抓出的退步

1. 820px 關蓋時，舊控制列的隱藏條件使兩個純鍵盤入口同時消失。新工具列需有獨立、可見的位置。
2. 320–430px 直向頁首高度未納入分配，使底部工具列超出可視範圍。已改為視窗高度的 flex stage，頁首與 main 分配高度。
3. 一般演奏的 Grid 規則套入純鍵盤，仍保留 56px 工具列空間；舊關蓋隱藏規則又藏住退出 X。已將一般版面與純鍵盤條件互斥。
4. 頁尾與原生捲軸外觀造成多餘控制感；需在精簡版面隱藏，保留實際水平瀏覽能力。

## 限制

Android 正式站 v10 的最新使用者回覆仍是「純鍵盤空白／沒有琴鍵」。本輪 IAB 視窗檢查不等於真機通過。Windows 原生瀏覽器模擬因工具無法確認網址而停止，未繞過限制；尚無正向 Android 真機複驗。
